**Mod_nicho_VZ**: Function to generate interaction networks based on the niche model of Williams and Martínez (2000).

**ri_and_X0**: Functions to simulate the species growth rates and initial abundances.

**tipoTIBA_VZ**: Function to classify species in an adjacency matrix according to their type (Top, Intermediate, Basal, Isolated).

**solEuler_peso_VZ**: Function to project the population dynamics of each species and species type.

**dinamica_metacomunidad_ciclosVero**: Functions to simulate metacommunity dynamics in a landscape.

**loop_metaCiclos**: Function to run the metacommunity dynamics of all the interaction networks.

**loop_experimentos_ciclos**: To run all the simulated experiments with different magnitudes of temporal variability and different initial conditions for all the interaction networks.
